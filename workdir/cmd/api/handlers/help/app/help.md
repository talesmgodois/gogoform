# Using the manual

The manual lists every page of GoGoForm in the menu on the left; the page
shown is the one selected there.

## Help panel

You do not need to open the manual to get help: the **?** button in the top
bar of every page shows the matching manual page in a panel on the right, and
the small **?** icons jump straight to the feature next to them.
